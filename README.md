# 集个戳戳 · H5 原型

每天打卡，朋友盖戳。集满了，奖励自己。

这是微信小程序上线前，用来在熟人群里验证玩法的 H5 版本。纯静态网页（HTML + 原生 JS，无需构建），放在 GitHub Pages；多人数据放在 Supabase 免费版。

## 玩法

1. **发一张集戳卡**：选模板（运动 / 背单词 / 早睡 / 自定义），写目标、选节奏（每天一次 / 每周几次 / 一次完成）、定天数（预设或自定义 1–90 天）和奖励。格子数自动算好，发完当天就开始，不用等任何人。还没集满时可以先预览集满后的分享卡。
2. **朋友接下当戳戳搭子**：分享链接给朋友，朋友接下时刻一个自己的专属戳（1–2 个字）。想使坏可以"加 2 格"，发卡人同意才生效。
3. **每天打卡，求盖戳**：拍张照、说一句，格子先显示"等盖戳"。
4. **搭子挑一个戳按下去**：戳盒分四栏，按下去"啪"一声，手机震动。
   - **朱批**：朕知道了 / 准奏 / 爱卿辛苦 / 此子可教 / 赏鸡腿一只 / 钦此（毛笔字）
   - **咕咕**：吉祥物鸽子咕咕的表情戳，比心 / 撒花 / 泪目 / 居然真做了 / 还不睡？/ 冲 / 稳
   - **动物园**：爪爪、稳稳、泥泥开局就有；章章、鹅大人、刺刺、啄啄、滚滚、鲤鲤随成就数解锁
   - **基础**：6 个图案戳、5 个文字戳、自己的专属戳
   - 或者"这不算"。
5. **成就**：15 个成就（普通 / 稀有 / 传说，含 2 个隐藏成就），解锁时弹窗并可生成单张成就卡；首页有连戳天数，"我的成就"里是成就墙和动物园。
6. **集满了，拆礼物**：礼物格打开，生成一张盖满戳的分享卡（1080×1440），长按保存发朋友圈或小红书。

## 规则

| 规则 | 说明 |
| --- | --- |
| 格子数 | 每天一次 = 天数；每周 N 次 = N × 天数 ÷ 7（四舍五入，至少 1 个）；一次完成 = 1 个 |
| 一次完成 | 在规定天数内提交完成证明，搭子盖上戳就开礼物；等盖戳期间不能重复提交 |
| 盖戳 | 打卡后 24 小时内，每个搭子都能盖一次，戳会叠在一起 |
| 结果 | 盖戳多于"这不算"就算盖上，平票也算 |
| 咕咕代盖 | 24 小时没人盖，咕咕代盖一个，卡不会卡住 |
| 成就 | 全部从已有数据推算，不加数据库表；"已看过"记在本机 |
| 这不算 | 当天可以补交一次，补交还不算就等明天 |
| 加 2 格 | 每天模式延长 2 天；每周模式目标 +2；一次完成不能加格 |
| 集满 | 每周模式可以提前集满，之后的打卡算"多集的" |
| 撕卡 | 发卡人可以随时撕掉，卡片直接结束 |

## 一、先在手机上看看（单机演示模式）

`js/config.js` 两项留空时，数据只存在当前浏览器里。顶部黑条可以**切换身份**（扮演发卡人和搭子）、**时间 +1 天**（几分钟走完一张卡）。演示模式下别人打不开你的链接。

## 二、发布到 GitHub Pages

仓库设为 Public → Settings → Pages → Deploy from a branch → `main` / `(root)` → Save。一两分钟后访问 `https://<用户名>.github.io/<仓库名>/`。

## 三、接上 Supabase（多人模式）

1. 在 [supabase.com](https://supabase.com) 新建项目，区域选 Singapore 或 Tokyo
2. SQL Editor → 粘贴 `supabase/schema.sql` → Run
3. Project Settings → API，复制 Project URL 和 anon public key，填进 `js/config.js`
4. 提交并推送

anon key 本来就是给浏览器用的公开密钥；不要把 service_role key 放进来。

## 原型阶段的限制

- 没有微信登录，身份是浏览器里存的名字，换手机就是新身份
- 数据库对匿名用户开放读写（不能删除），只适合熟人测试
- 专属戳只做了简单的字数和脏字过滤；小程序版要接微信内容安全接口
- 没有打卡提醒；在微信里分享出去是普通链接

## 目录

```
index.html          入口
css/style.css       样式
js/logic.js         规则（纯函数，小程序可直接复用）
js/store.js         数据层：单机演示 / Supabase
js/card.js          分享卡、成就卡
js/art.js           所有戳、咕咕、动物、成就徽章（SVG，网页和分享卡共用）
js/achievements.js  成就、连戳、咕了几天
js/glyphs.js        毛笔字 / 快乐体的字形轮廓（由 scripts/glyphs.py 生成）
js/app.js           页面、盖戳交互与路由
js/config.js        Supabase 配置
supabase/schema.sql 建表脚本
tests/              测试：node tests/logic.test.mjs && node tests/achievements.test.mjs
```

## 字体

朱批用的毛笔字来自 Ma Shan Zheng，咕咕和徽章上的字来自站酷快乐体（ZCOOL KuaiLe），都是 SIL Open Font License 1.1。只把用到的字转成矢量轮廓放进 `js/glyphs.js`，页面不需要加载字体文件。要加新字，改 `scripts/glyphs.py` 里的字表重新生成。
